# v3.10.0

Tiger Studio can now see the scale's screen without anyone typing a code, and
the scale asks about an update the way the rest of the family does.

## Added

- **The scale publishes its live view to the account.** Every heartbeat now
  carries `lan_live`, `lan_access_code` and `lan_url` — and writes them
  immediately when the switch or the code changes rather than waiting for the
  next beat. Tiger Studio can take a screenshot of the panel with nothing typed
  in. The stream also answers cross-origin now, so a renderer can fetch a frame
  directly. Both are documented in `docs/TELEMETRY.md` and `docs/API.md`.

## Changed

- **Settings calls it "Live view", with an eye.** The row said "LAN" and drew
  two joined nodes, which named the plumbing rather than the thing you get. The
  menu entry, the screen it opens and the switch inside it now all use the same
  word, in all eleven languages.
- **The update prompt is its own card**, the one Tiger Touch shows, in its
  orange: the download glyph, the question, `v<installed> > v<latest>`, then
  Later or Yes. It used to be the generic two-word dialog with no version in it.
  Later still snoozes for 24 hours.
