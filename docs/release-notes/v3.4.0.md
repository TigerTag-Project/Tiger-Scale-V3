# v3.4.0

The Update screen grew up: it shows what you have, highlights what is
waiting, and answers the question you actually have before pressing Install
— yes, your WiFi, account and calibration are kept. And Settings now flags a
waiting update from the list itself.

## Changed

- **The Update screen was rebuilt from scratch.** Your installed version
  lives in a proper row; a new release arrives as an amber "New version"
  banner with a full-size blue Install button and, right underneath, the
  reassurance that matters: *WiFi, account and calibration are kept*. Up to
  date shows a green check and says so in plain words; a failed check shows
  a red badge with a Retry button instead of a dead error label. The
  install progress ring — percentage, "Do not power off" — is unchanged.
- **Settings tells you an update is waiting.** Once the scale's background
  check has spotted a newer release, the Update row's icon turns orange and
  its value spells the move — "3.3.1 > 3.4.0" — so the news reaches you
  without opening anything.

## Known issues

- On-tag metadata reads still fall back to the cached values; a spool never
  seen before may show no brand or material.

## Updating

- **Over the air** from **Settings > Update** — keeps your WiFi credentials,
  TigerTag session and calibration.
- **Over USB** with `bash scripts/flash.sh --fs` — same guarantee.
- **From the browser** via the
  [web installer](https://tigertag-project.github.io/Tiger-Scale-V3/) —
  always installs this latest version, but as a **fresh install**: it resets
  the scale to factory state and the first-boot setup walks you back through
  language, WiFi, account and calibration.
