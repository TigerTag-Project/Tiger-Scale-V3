# v3.7.3

The display board with the **B** on it has been out of stock almost everywhere,
and people kept ending up with the one without it — a board that looked right,
wired up the same, and then had no firmware that would run on it. It does now.

Nothing changes on a scale you already own. This release exists for the boards
that could not run the previous one.

## Added

- **The Waveshare ESP32-S3-Touch-LCD-3.5 — the one whose silkscreen has no B —
  runs the scale.** It takes the same wiring, the same load cell, the same
  readers and the same printed case as the -3.5B; comparing the two official
  schematics net by net, a single GPIO differs. What is not the same is the
  screen controller, so each board needs its own firmware, and installing the
  wrong one leaves you with a scale that flashes perfectly and never lights up.

  Nothing about that is left to guesswork: **the web installer now asks which
  board you have** instead of which wiring you built, with the two names exactly
  as they are printed on the board. Updates over the air are just as careful —
  each board is served its own image, and a scale can only ever be offered the
  one that matches it.

  > This build is derived from the official schematic and has not yet been run on
  > a physical -3.5. If you have one, we would very much like to hear how it goes.
  > The worst case is a screen that stays dark, which a reflash undoes.

- **The scale reports which board it is** on its local `/api/status`. From the
  outside the two are indistinguishable, which makes helping someone diagnose one
  needlessly hard.

## Changed

- **The installer asks about your board, not your wiring.** The SPI and I²C
  reader builds are no longer offered: every scale in use is wired HSU, and the
  over-the-air channel has only ever served the HSU build anyway, so those two
  options did nothing but present a choice whose failure mode is silent. They
  still build from source — see `docs/INSTALLATION.md`.

## For a scale you already own

Nothing changes. Update from **Settings > Update** as usual: your WiFi
credentials, TigerTag session and calibration are kept, and the image you are
offered is the same one you would have been offered before, with one addition —
it can now say which board it is running on.

## Known issues

- On-tag metadata reads still fall back to the cached values; a spool never
  seen before may show no brand or material.

## Updating

- **Over the air** from **Settings > Update** — keeps your WiFi credentials,
  TigerTag session and calibration.
- Or from the [web installer](https://tigertag-project.github.io/Tiger-Scale-V3/),
  which always serves the current release.
