# v3.7.4

The scale can finally write the languages it speaks.

Until now every accented letter — é, ü, ñ, ç, ą — drew as a small empty box,
because the fonts on the device carried plain ASCII and Han and nothing in
between. Nobody saw it in the interface, for a simple reason: the translations
had been written around it, in unaccented spelling. "Pret" for Prêt. "MATERIAU"
for MATÉRIAU. German went further and spelled its umlauts out, BEHAELTER for
BEHÄLTER.

Where it did show was in text the scale does not write itself. An account named
Günter appeared as G_nter on the weigh screen. So did a WiFi network, a filament
brand, anything typed by someone else.

## Added

- **Accented Latin letters render.** Latin-1 Supplement and Latin Extended-A in
  full, in the same Montserrat the rest of the interface uses, so they sit beside
  the plain letters without looking imported. Whole blocks rather than the
  letters our own strings happen to need, because the point is the text nobody
  here writes: your account name, your network, your filament.

## Changed

- **Nine languages are spelled the way they are spelled.** French, Spanish,
  German, Italian, Polish and both Portuguese variants, across every screen —
  and Chinese, which was already correct because its font already existed. Two
  of those corrections are not cosmetic: the confirmation button read "Si" in
  Spanish and Italian, which means "if". It now reads "Sí" and "Sì".
- **Each language names itself as it writes itself** in the language picker:
  Français, Español, Português.

## For a scale you already own

Update from **Settings > Update** as usual. Your WiFi credentials, TigerTag
session and calibration are kept. If your account name has an accent in it, the
weigh screen will show it properly for the first time.

## ESP32-S3-Touch-LCD-3.5

The build for the board without the B, published in v3.7.3, has now been
confirmed working by the first person to run it on real hardware. Its two
early faults — a panel that stayed dark, and a reset that never fired — were
fixed in that same release.

## Known issues

- On-tag metadata reads still fall back to the cached values; a spool never
  seen before may show no brand or material.
- Spanish and Portuguese questions are not yet opened with the inverted mark
  (`¿`). The glyph is now available; the wording pass is not done.

## Updating

- **Over the air** from **Settings > Update** — keeps your WiFi credentials,
  TigerTag session and calibration.
- Or from the [web installer](https://tigertag-project.github.io/Tiger-Scale-V3/),
  which always serves the current release.
