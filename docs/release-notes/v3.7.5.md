# v3.7.5

A release about how the scale feels under a finger, and about the remote view
telling the truth.

## Changed

- **The buttons answer the press, not the release.** Tare, Settings, the back
  arrow and the scroll arrows all used to wait for the finger to lift before
  anything happened, which on a screen this size reads as hesitation. They now
  react on contact. The tare itself still runs on the release, so sliding off
  the button before letting go still cancels it.
- **The tare button confirms.** Pressing it changed nothing on screen: the scale
  re-zeroed in silence and the only evidence was the weight moving. It now
  lights green for a moment — the fill only, no fade, one flat colour on and off.
- **The restart screen is a screen.** Settings > Restart used to draw white
  monospace text straight over the interface, and it could not render an accent:
  in French it read "Red|-marrage". It is now built like every other screen,
  with a spinner and the version.
- **The remote view matches the glass.** The weight sent over the local
  WebSocket was floored at 5 g, so anything lighter — including the negative
  reading you briefly get when a spool is lifted off before the auto-tare
  catches up — went out as zero. It is now exactly what the big number on the
  panel shows. Tiger Studio draws a virtual copy of that panel from this feed,
  and the two now agree. The scale's own web page reads the same field, so it
  became faithful with it.

## Known issues

- On-tag metadata reads still fall back to the cached values; a spool never
  seen before may show no brand or material.
- Spanish and Portuguese questions are not yet opened with the inverted mark
  (`¿`). The glyph is available; the wording pass is not done.

## Updating

- **Over the air** from **Settings > Update** — keeps your WiFi credentials,
  TigerTag session and calibration.
- Or from the [web installer](https://tigertag-project.github.io/Tiger-Scale-V3/),
  which always serves the current release.
