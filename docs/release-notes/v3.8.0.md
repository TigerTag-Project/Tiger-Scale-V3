# v3.8.0

The scale can be switched off.

## Added

- **A power-off row in Settings.** There is no power button on this board, so a
  scale running on its battery had no way to be switched off at all — unplugging
  the USB cable moves it onto the cell rather than stopping it. The new row sits
  under Restart, and its confirmation says how to switch the scale back on:
  plug the USB cable in. Wi-Fi, account and calibration are kept, like every
  other restart on this device.

  With the cable connected the row explains that it cannot act — powering off
  with USB present would drop the rails and bring them straight back, which
  would read as an unexplained reboot. Unplug, and the row turns amber and works.

## Changed

- **The Settings list follows the cable.** Unplugging or plugging in while the
  list is open now updates it in place, at the same scroll position, instead of
  showing whatever was true when the screen opened.
- **A settings row that opens nothing no longer shows a chevron.** The chevron
  is what tells you a row leads somewhere.
