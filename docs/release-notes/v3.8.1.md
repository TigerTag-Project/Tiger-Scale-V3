# v3.8.1

## Fixed

- **The power-off row no longer appears on a scale without a battery.** The
  battery is optional on this board, and without one the USB cable is the only
  supply — unplugging it *is* switching the scale off. The row shipped in v3.8.0
  regardless, so those scales showed a control that could never do anything.

  A scale that cannot report its battery state at all is treated the same way and
  hides the row too: the power-off itself goes through the same chip, so a scale
  that cannot be asked about its cell could not be switched off either.
