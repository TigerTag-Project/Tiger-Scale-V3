Install TigerScale V3

Plug the board in over USB-C and click Install. No toolchain, no command line.

1. How are your NFC readers wired?

The PN532 transport is fixed at compile time. Picking the wrong one gives you a scale that detects no reader at all, with no error message to explain it — so this choice matters more than it looks.

2. Install

Serve this page over HTTPS to install.
This browser cannot flash a device.

Installing needs Web Serial, which today means Chrome, Edge or Opera on a desktop. Safari and Firefox do not implement it, and neither does any mobile browser. Alternatively, flash from the command line — see the installation guide.

A first install erases everything on the board, including any saved WiFi credentials, and writes the bootloader, the partition table, the firmware and the web interface. That is what you want on new hardware. To update a scale you already set up, use Settings → Update on its touchscreen, or reflash over USB with bash scripts/flash.sh, both of which keep your settings.

After it finishes

The scale boots to its splash screen and then asks for WiFi. Pick your network on the touchscreen, sign in to your TigerTag account from Settings → Cloud, then run Settings → Calibration with a known weight. Put a tagged spool on the platform and it identifies itself.

If the scale reports no readers, the transport above did not match your wiring — come back, pick another and install again. Everything else is in the troubleshooting guide.
